# Email Thread Summary

Read the available thread in chronological order, accounting for quoted duplicates and later messages that revise earlier decisions. If part of the thread is unavailable, state the gap briefly.

Give a concise summary of the current outcome, decisions, and unresolved questions. Highlight the user's action items with the next action, stated deadline, and relevant dependency. Keep other people's responsibilities separate, and do not invent owners or dates. If no action is required from the user, say so.

Use polite, direct language with only the facts needed for the user's next action. Link to source messages when available. Highlight action items in the response; send reminders or messages only if separately requested.
